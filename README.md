# Google Advanced Data Analytics — Coursework

This repository contains my coursework and projects from the **Google Advanced Data Analytics Professional Certificate** (Coursera), covering Courses 1 through 6, along with a related **Python for Everybody / Intro to Python** specialization completed alongside it.

Course 1 introduces the data professional role and the **PACE workflow (Plan, Analyze, Construct, Execute)** used to structure data projects. Courses 2 through 6 build progressively on the same case study — **Waze**, a navigation app — using a consistent dataset to apply increasingly advanced techniques: exploratory data analysis, statistics, regression, machine learning, and a final capstone.

## Structure

| Folder | Course | Focus |
|---|---|---|
| `course1-foundations-of-data-science/` | Course 1 | Role of data professionals, the PACE project workflow, data ethics, effective communication |
| `course2-go-beyond-the-numbers/` | Course 2 | Exploratory data analysis, data cleaning, Tableau visualization (Waze) |
| `course3-power-of-statistics/` | Course 3 | Descriptive statistics, probability distributions, hypothesis testing (Waze) |
| `course4-regression-analysis/` | Course 4 | Linear & logistic regression, model evaluation (Waze) |
| `course5-machine-learning/` | Course 5 | Supervised & unsupervised ML, feature engineering, model tuning (Waze) |
| `course6-capstone/` | Course 6 | End-to-end capstone: full analytics pipeline from EDA to ML model, business recommendation (Salifort) |

## Tools & Skills

Python (pandas, NumPy, scikit-learn), Jupyter Notebook, Tableau, statistical hypothesis testing, regression modeling, machine learning (classification/clustering), data visualization, stakeholder communication, PACE project workflow.

## Note

This is a learning archive documenting progression through the certificate program, not a single polished case study.
