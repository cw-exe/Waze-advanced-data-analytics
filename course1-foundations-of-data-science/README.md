# Course 1: Foundations of Data Science

**Google Advanced Data Analytics Professional Certificate — Course 1 of 6**

## What this course was about

This first course doesn't have any coding or a dataset attached to it — it's more about setting the foundation before diving into the technical stuff in later courses. It covers what data professionals actually do day-to-day, the different roles in the field (data analyst vs. data scientist and where they overlap), and the tools people typically use.

The big thing I took away from this course was the **PACE framework** — a way of structuring a data project:

- **Plan** — figure out what problem you're actually solving
- **Analyze** — dig into the data and understand what you're working with
- **Construct** — build the model, analysis, or output
- **Execute** — share what you found in a way stakeholders can actually use

It sounds simple, but it's the framework that shows up again in every project from Course 2 onward, so it's worth having a solid handle on it early.

## Other things covered

- How data-driven decisions actually affect a business
- Career paths in data (and where "advanced data analyst" and "entry-level data scientist" overlap)
- Data ethics and privacy — being thoughtful about how data is collected and used
- Communicating findings to people who aren't technical

## Why this folder is different

Every other folder in this repo has a notebook and real analysis. This one doesn't — it's the "before you start coding, here's how to think about this" course. I'm including it anyway because the PACE framework it introduces is the backbone for how I approached the Waze project in every course after this one.
